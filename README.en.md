## Featured project

### [Order API — Node.js and MongoDB](https://github.com/Alvaromarinho75/jitterbit-API-challenge)

A personal project based on a systems-integration technical challenge. It accepts order fields in Portuguese, maps them to an English model and persists them in MongoDB.

- **Back-end:** CRUD with Express and Mongoose, JWT authentication, input validation and HTTP error handling.
- **Data:** a unique index and duplicate-order handling, including concurrent creation attempts.
- **Verification:** 26 automated tests, including HTTP integration with a real, temporary MongoDB instance.
- **Documentation:** an OpenAPI contract, request examples, setup instructions and design decisions, with Portuguese and English READMEs.
